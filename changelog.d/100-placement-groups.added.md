- Workloads can be placed together: `felixd run --group name=a,b` (on every member) puts the group in each member's spec, the scheduler places the whole group with one `group` record or not at all, and a node claims a member only where that record puts it, for at most `--group-bound-ms` (180 s), then by first claim wins with the new placement reason `group-bound`. `felixd ps` lists each group as `waiting`, `together` or `split`, and admission rejects a malformed group. Run groups only once every node has this build (#100).
